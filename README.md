# СӨЗ — самоучитель казахского языка

Приватный проект на **Vue 3 + Vite + TypeScript + Pinia + Vue Router**. Версия: **0.4.0 — автоматическая казахская аудиобиблиотека**.

СӨЗ предназначен для самостоятельного изучения казахского языка **людьми любого возраста**, а не только школьниками. Со временем программа должна охватывать A0–C1. Сейчас доступны первые демонстрационные материалы A1.

## Главная страница

Путь: `/#/`. Это настоящая рабочая демонстрация пяти форматов с использованием переиспользуемых Vue-компонентов:

1. **Словарная карточка с иллюстрацией**: локальная SVG-иллюстрация, скрываемый перевод, пример, произношение при наличии казахского голоса, избранное, «выучено».
2. **Фразовая карточка**: скрываемый перевод и разбор по частям.
3. **Текстовый пост**: адаптированный рассказ, построчный перевод, мини-словарь, отметка «прочитано».
4. **Грамматика**: правило, формула, примеры и примечания.
5. **Упражнение**: выбор правильного ответа с объяснением результата.

На главной также отображаются фактические показатели учебного прогресса: слова, тексты, упражнения и избранное. Прогресс меняется по нажатию и сохраняется в `localStorage` на данном устройстве.

**Все пять форматов представлены прямо на главной**, а ссылки ведут в полноценные разделы: слова, фразы, тексты, практика, грамматика. Остальные упражнения работают в своих разделах: ввод ответа, порядок слов, сопоставление пар.

## Иллюстрации

Все пять стартовых слов имеют SVG-изображения в `src/assets/illustrations/`. Поля `image` и `imageAlt` опциональны в типе `WordPost`, чтобы слова без подходящего изображения тоже поддерживались без изменения компонента. SVG импортируются средствами Vite и корректно работают с относительным base path, в том числе при размещении в подпапке.

## Запуск и проверка

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
npm run test
npm run build
npm run preview
```

`npm run dev` показывает сайт по адресу, указанному Vite в терминале (обычно http://localhost:5173). `npm run preview` локально показывает собранный `dist`.

GitHub Actions выполняет тесты и сборку на каждом push; после успешного выполнения артефакт `soz-site-preview` содержит собранный сайт для локального просмотра.

## Приватность

Репозиторий остаётся **private**. **Публикация через GitHub Pages подготовлена**: `.github/workflows/pages.yml` автоматически тестирует и собирает Vue-проект и разворачивает `dist/` после отправки изменений в `main`. Нужно один раз включить GitHub Pages в **Settings → Pages → Source: GitHub Actions**. Без этого шага workflow может завершиться ошибкой на `configure-pages`. Публикация с приватного репозитория требует подходящего плана GitHub (GitHub Pro/Team/Enterprise); GitHub Free требует публичный репозиторий. Приватность исходников сохраняется, но сайт на Pages **публичен**. Пока нет авторизации или частного хостинга. Для локального просмотра запускать проект самостоятельно. Данные прогресса не синхронизируются между устройствами.

См. [PROJECT_CONTEXT.md](./PROJECT_CONTEXT.md).

## Автоматическая генерация казахских MP3 (v0.4.0)

В приложении уже поддерживаются озвученные слова, примеры к словам, фразы, абзацы рассказов и примеры грамматики. Пользователь выбирает **Айгүл** (женский голос) или **Дәулет** (мужской голос) и скорость **1× / 0,75×**. Настройки сохраняются локально. До появления готовых MP3 кнопка использует доступный на устройстве Web Speech API (возможность казахского голоса зависит от устройства).

### Однократная настройка Azure

1. Создай в [Azure Portal](https://portal.azure.com/) ресурс Speech (если доступен — бесплатный F0). Скопируй **Key 1** и **Region** из раздела Keys and Endpoint.
2. Открой [Actions secrets](https://github.com/nick-osinskiy/qazaq-tili/settings/secrets/actions) и добавь два **Repository secrets**:
   - `AZURE_SPEECH_KEY` — ключ Speech (только в GitHub Secrets; никогда в исходном коде).
   - `AZURE_SPEECH_REGION` — короткий идентификатор региона, например `westeurope` (только тот, который указан в твоём Azure-ресурсе).
3. Открой [Actions → Generate Kazakh audio](https://github.com/nick-osinskiy/qazaq-tili/actions/workflows/audio.yml) и нажми **Run workflow → main → Run workflow**.

После этого при изменении файла `src/data/content.ts` генерация запускается автоматически. Скрипт `scripts/speech-catalog.mjs` извлекает казахские тексты из текущего каталога TypeScript через AST (без ручного списка и дублирования). `scripts/generate-audio.mjs` генерирует **только отсутствующие или устаревшие** записи двух голосов. MP3 сохраняются в `public/audio/kk-KZ/` и регистрируются в `src/data/audio-index.json`. GitHub Actions делает коммит аудио в `main`; успешное завершение workflow автоматически инициирует повторный деплой Pages. Таким образом, после первичной настройки добавленные в каталог слова и фразы озвучиваются автоматически.

Обратите внимание: действие `Generate Kazakh audio` при отсутствии секретов завершится без генерации, выдаст notice и не будет выводить секреты. MP3 **ещё не сгенерированы**, пока секреты Azure не настроены. Первоначально ожидается около 21 фрагмента × 2 голоса. Лимит одного запуска — **80 MP3**, чтобы не расходовать неожиданно большую квоту при массовых изменениях. Если материалов станет больше, генерацию можно повторить вручную или изменить лимит осознанно.

Локальная проверка без затрат на API:
```bash
npm install
npm run audio:plan
npm run test
npm run build
```

Непосредственная генерация, когда переменные установлены:
```bash
AZURE_SPEECH_KEY=... AZURE_SPEECH_REGION=... npm run audio:generate
```
Ключ не нужно передавать другим людям или вводить на публичном сайте. Подключение Azure может потребовать платёжные данные; следи за тарифом и квотой Speech.

Официальная документация: https://learn.microsoft.com/en-us/azure/ai-services/speech-service/rest-text-to-speech

### Масштабирование

Пока MP3 сохраняются непосредственно в репозитории для простоты и бесплатной отдачи через Pages. При большом количестве материалов стоит перенести аудиобиблиотеку в объектное хранилище/CDN — GitHub не предназначен для хранения очень больших наборов бинарных файлов. Все записи ИИ рекомендуется выборочно проверять на правильность ударения и произношения.
