# СӨЗ — самоучитель казахского языка

Приватный проект на **Vue 3 + Vite + TypeScript + Pinia + Vue Router**. Версия: **0.3.0 — интерактивная главная страница**.

СӨЗ предназначен для самостоятельного изучения казахского языка **людьми любого возраста**, а не только школьниками. Со временем программа должна охватывать A0–C1. Сейчас доступны первые демонстрационные материалы A1.

## Главная страница

Путь: `/#/`. Это настоящая рабочая демонстрация пяти форматов с использованием переиспользуемых Vue-компонентов:

1. **Словарная карточка с иллюстрацией**: локальная SVG-иллюстрация, скрываемый перевод, пример, произношение при наличии казахского голоса, избранное, «выучено».
2. **Фразовая карточка**: скрываемый перевод и разбор по частям.
3. **Текстовый пост**: адаптированный рассказ, построчный перевод, мини-словарь, отметка «прочитано».
4. **Грамматика**: правило, формула, примеры и примечания.
5. **Упражнение**: выбор правильного ответа с объяснением результата.

На главной также отображаются фактические показатели учебного прогресса: слова, тексты, упражнения и избранное. Прогресс меняется по нажатию и сохраняется в `localStorage` на данном устройстве.

**Все пять форматов представлены прямо на главной**, а ссылки ведут в полноценные разделы: слова, фразы, тексты, практика, грамматика. Остальные упражнения работают в своих разделах: ввод ответа, порядок слов, сопоставление пар.

## Иллюстрации

Все пять стартовых слов имеют SVG-изображения в `src/assets/illustrations/`. Поля `image` и `imageAlt` опциональны в типе `WordPost`, чтобы слова без подходящего изображения тоже поддерживались без изменения компонента. SVG импортируются средствами Vite и корректно работают с относительным base path, в том числе при размещении в подпапке.

## Запуск и проверка

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
npm run test
npm run build
npm run preview
```

`npm run dev` показывает сайт по адресу, указанному Vite в терминале (обычно http://localhost:5173). `npm run preview` локально показывает собранный `dist`.

GitHub Actions выполняет тесты и сборку на каждом push; после успешного выполнения артефакт `soz-site-preview` содержит собранный сайт для локального просмотра.

## Приватность

Репозиторий остаётся **private**. **GitHub Pages не включён**, поскольку приватный репозиторий сам по себе не гарантирует приватность опубликованного сайта. Пока нет авторизации и безопасного хостинга. Для локального просмотра запускать проект самостоятельно. Данные прогресса не синхронизируются между устройствами.
