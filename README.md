# СӨЗ — изучение казахского языка

Приватный учебный проект на **Vue 3, Vite, TypeScript, Vue Router и Pinia**. Интерфейс рассчитан прежде всего на смартфоны. Версия: **0.2.0**.

## Что реализовано

- **Карточки слов** — казахское слово, транскрипция, скрытый перевод, пример, озвучивание через Web Speech API, избранное, «выучено».
- **Карточки фраз** — контекст общения, скрытый перевод, разбор на смысловые части, озвучивание, избранное.
- **Текстовые посты** — рассказы из нескольких абзацев, построчный перевод, мини-словарь, отметка «прочитано».
- **Упражнения** — выбор правильного ответа, ввод пропущенного слова, сборка предложения, сопоставление пар. Проверка и объяснение.
- **Посты с грамматикой** — правило, формула, примеры, примечание, раскрытие дополнительных примеров, ссылка на связанное упражнение при наличии.
- Единые карточка-оболочка, кнопки избранного и озвучивания, адаптивный дизайн.
- Сохранение избранного и учебного прогресса в localStorage (на одном устройстве).
- 12 демонстрационных материалов A1, доступных через разделы в верхней навигации.

## Локальный запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
npm run test
npm run build
```

## Принципы

- Весь фронтенд на Vue 3 с Composition API, никакого независимого «временного» DOM-интерфейса.
- Каждый материал имеет стабильный `id`, `kind`, `level`, `tags`. Компоненты принимают типизированные данные через `item`.
- Контент отделён от интерфейса. В дальнейшем можно заменить TypeScript-массивы данными API/CMS без переписывания карточек.
- Казахские тексты помечены `lang="kk"`. Предусмотрены кнопки с подписями для скринридеров и навигация с клавиатуры.
- Озвучивание зависит от наличия поддержки Web Speech API и казахского голоса в браузере/операционной системе.
- **Приватный GitHub-репозиторий не делает опубликованное веб-приложение закрытым.** Публичную публикацию не включаем без отдельного решения по доступу.
