# СӨЗ — контекст проекта

Дата: 2026-11-10. Текущая версия: 0.4.0.

## Назначение
Полноценный интерактивный самоучитель казахского языка с русскоязычным интерфейсом, для людей любого возраста. Постепенно развиваем базу материалов от самых основ (A0, A1) до продвинутого владения (C1). Не считать приложение исключительно школьным/детским продуктом. Дизайн современный, нейтральный, mobile-first.

## GitHub
Репозиторий `nick-osinskiy/qazaq-tili` **public по решению пользователя на время разработки**, GitHub Pages работает на https://nick-osinskiy.github.io/qazaq-tili/. Не менять видимость без запроса.

## Технологии
Vue 3 Composition API (`script setup`), TypeScript, Vite, Vue Router, Pinia, CSS-переменные. Никаких временных интерфейсов на чистом HTML/JS вместо Vue. PWA планируется, ещё не реализована.

## Что в коде
- Отдельная главная `src/views/HomeView.vue` — настоящая демонстрация всех пяти форматов, герой-блок, блоки возможностей, CTA, обзор локального прогресса.
- Универсальные WordCard, PhraseCard, ReadingPost, ExerciseCard и GrammarPost в `src/components/`.
- `WordCard` поддерживает необязательные `image`, `imageAlt`; пять начальных слов имеют иллюстрации в `src/assets/illustrations/`.
- Демонстрационный учебный контент A1 — `src/data/content.ts`.
- Упражнения: choice, fill, ordering, matching. На главной показывается один пример, остальные доступны в разделе практики.
- Избранное, известные слова, прочитанные тексты, результаты упражнений — Pinia + `localStorage`.
- Vue Router использует hash history для возможности размещения на статическом хостинге.
- Файлы тестов в `tests/`, CI в `.github/workflows/ci.yml`. Сборка добавляется как артефакт CI после успешной проверки. Новый GitHub Pages workflow в `.github/workflows/pages.yml` запускает тесты/сборку и деплой `dist` (нужна предварительная активация Pages в настройках).

## Границы MVP
Нет настоящей серверной авторизации, редактора материалов, API, синхронизации прогресса между устройствами, защищённого хостинга или продвинутых курсов. Включены генератор и проигрыватель Azure Speech MP3 с запасным Web Speech API. До добавления Azure Secrets готовых файлов нет; браузерный вариант зависит от поддержки устройства.

## Следующие этапы
1. Структура последовательных уроков и модулей A0/A1, выбор курса и продолжение с текущего места.
2. Наращивание контента и иллюстрированного словаря с тематическими подборками.
3. Повторение слов по интервалам, закладки, фильтры по уровню, тематике и формату.
4. Редактор учебных материалов и система проверки их качества.
5. Аккаунты, безопасный хостинг, синхронизация прогресса, PWA/офлайн-режим.

## Правила работы
Актуальный код `main` — источник истины о реализации, а не предыдущие разговоры. Развивать поэтапно, сохранять функции, выполнять тесты/сборку после изменения, делать коммит и сообщать ссылки на коммит и репозиторий. Не утверждать, что сайт опубликован, пока он реально недоступен по подтверждённому URL.

## Автоматическая аудиобиблиотека v0.4.0
- `scripts/speech-catalog.mjs` извлекает казахский текст карточек/примеров/рассказов из `src/data/content.ts` через TypeScript AST.
- `scripts/generate-audio.mjs` делает MP3 с голосами `kk-KZ-AigulNeural`, `kk-KZ-DauletNeural` только для отсутствующих или изменённых текстов. Без Azure-ключей генерация не выполняется; `npm run audio:plan` работает без API.
- `src/data/audio-index.json` содержит текст и относительный путь MP3 на оба голоса. `src/audio.ts` проверяет совпадение текста; `SpeakButton.vue` использует локальный MP3 или Web Speech API. `AudioSettings.vue` и `src/stores/audio.ts` — единые настройки голоса и скорости (1×/0,75×).
- `.github/workflows/audio.yml` автоматически запускается при изменении каталога и может запускаться вручную; MP3 в `public/audio` коммитятся ботом. `.github/workflows/pages.yml` также запускается после успешной генерации (workflow_run), так как коммиты от GITHUB_TOKEN сами не инициируют push workflow.
- **ОЖИДАЕТ ДЕЙСТВИЯ ПОЛЬЗОВАТЕЛЯ**: создать ресурс Azure Speech и добавить два repository secrets `AZURE_SPEECH_KEY`, `AZURE_SPEECH_REGION`. После этого один раз вручную запустить workflow `Generate Kazakh audio`. Ни одной готовой записи Azure не утверждать, пока workflow не сгенерирует MP3.
- Держать ключ только в GitHub Secrets, не коммитить ключ/запросы и не предоставлять публичному Vue-приложению. Лимит 80 MP3 за запуск.
