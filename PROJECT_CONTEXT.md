# СӨЗ — контекст проекта

Дата обновления: 2026-11-10. Версия исходников: 0.2.0.

## Назначение
Частное приложение для изучения казахского языка с русскоязычным интерфейсом. Репозиторий `nick-osinskiy/qazaq-tili` должен оставаться **private**.

## Зафиксированный стек
Vue 3 + Composition API + TypeScript, Vite, Vue Router, Pinia, единые CSS-переменные. Mobile-first. PWA планируется следующим этапом, не следует считать её реализованной.

## Реализовано
Базовая Vue-структура, маршруты и адаптивная витрина контента.
Пять компонентов материалов: WordCard, PhraseCard, ReadingPost, ExerciseCard, GrammarPost.
Упражнения четырёх форматов: choice, fill, ordering, matching.
Типизированные контракты в `src/types/content.ts`, демонстрационные примеры в `src/data/content.ts`.
Общие CardFrame, FavoriteButton, SpeakButton.
Pinia и localStorage для прогресса; проверки в `tests/`.

## Ограничения
Данные демонстрационные A1, не полный учебный курс. Прогресс локальный, без синхронизации между устройствами или авторизации. Встроенное TTS не гарантирует казахский голос на всех платформах. Автоматические тесты добавлены, но их выполнение следует проверить в CI/локально после установки зависимостей. Нет серверного API, личных аккаунтов или защищённого хостинга. Не публиковать сайт без согласования модели приватного доступа.

## Ближайшие задачи
1. Подключить CI с `npm run test` и `npm run build`, исправить найденные ошибки.
2. Составить полноценную контентную структуру уровней и уроков (A1 → B1) и редактор публикаций.
3. Отдельные экраны материала, тренировка повторения, статистика, подборки.
4. PWA, офлайн-режим и продуманная синхронизация прогресса.
5. Защита доступа к приложению независимо от приватности репозитория.

## Правила
Не начинать заново и не переносить фронтенд с «чистого» JS. Каждую новую функцию делать Vue-компонентом, сохранять схему контента, версионировать изменения и давать ссылку на коммит. Код репозитория — источник истины для реализованного состояния.
