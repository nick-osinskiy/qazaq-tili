# СӨЗ — контекст проекта

Дата: 2026-11-10. Текущая версия: 0.3.0.

## Назначение
Полноценный интерактивный самоучитель казахского языка с русскоязычным интерфейсом, для людей любого возраста. Постепенно развиваем базу материалов от самых основ (A0, A1) до продвинутого владения (C1). Не считать приложение исключительно школьным/детским продуктом. Дизайн современный, нейтральный, mobile-first.

## GitHub
Репозиторий `nick-osinskiy/qazaq-tili` **private**. Не менять видимость и не публиковать сайт публично без отдельного согласования решения по доступу. GitHub Pages пока не настроен; даже приватный исходный код не делает опубликованный сайт приватным.

## Технологии
Vue 3 Composition API (`script setup`), TypeScript, Vite, Vue Router, Pinia, CSS-переменные. Никаких временных интерфейсов на чистом HTML/JS вместо Vue. PWA планируется, ещё не реализована.

## Что в коде
- Отдельная главная `src/views/HomeView.vue` — настоящая демонстрация всех пяти форматов, герой-блок, блоки возможностей, CTA, обзор локального прогресса.
- Универсальные WordCard, PhraseCard, ReadingPost, ExerciseCard и GrammarPost в `src/components/`.
- `WordCard` поддерживает необязательные `image`, `imageAlt`; пять начальных слов имеют иллюстрации в `src/assets/illustrations/`.
- Демонстрационный учебный контент A1 — `src/data/content.ts`.
- Упражнения: choice, fill, ordering, matching. На главной показывается один пример, остальные доступны в разделе практики.
- Избранное, известные слова, прочитанные тексты, результаты упражнений — Pinia + `localStorage`.
- Vue Router использует hash history для возможности размещения на статическом хостинге.
- Файлы тестов в `tests/`, CI в `.github/workflows/ci.yml`. Сборка добавляется как артефакт CI после успешной проверки.

## Границы MVP
Нет настоящей серверной авторизации, редактора материалов, API, синхронизации прогресса между устройствами, защищённого хостинга или продвинутых курсов. Озвучивание через Web Speech API зависит от поддержки казахского синтеза речи устройством.

## Следующие этапы
1. Структура последовательных уроков и модулей A0/A1, выбор курса и продолжение с текущего места.
2. Наращивание контента и иллюстрированного словаря с тематическими подборками.
3. Повторение слов по интервалам, закладки, фильтры по уровню, тематике и формату.
4. Редактор учебных материалов и система проверки их качества.
5. Аккаунты, безопасный хостинг, синхронизация прогресса, PWA/офлайн-режим.

## Правила работы
Актуальный код `main` — источник истины о реализации, а не предыдущие разговоры. Развивать поэтапно, сохранять функции, выполнять тесты/сборку после изменения, делать коммит и сообщать ссылки на коммит и репозиторий. Не утверждать, что сайт опубликован, пока он реально недоступен по подтверждённому URL.
